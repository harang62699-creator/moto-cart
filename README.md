# 수입자동차 배출가스·소음 인증신청 지원 시스템

## 프로젝트 개요
- **이름**: 수입자동차 배출가스·소음 인증신청 지원 시스템
- **목표**: 수입자동차의 배출가스 및 소음 인증신청을 위한 첨부서류 안내 및 작성 지원 웹 앱
- **기술 스택**: Hono + TypeScript + TailwindCSS (CDN) + Cloudflare Pages

## 완성된 기능

### 1. 홈 화면
- 신청 유형별 카드 메뉴 (인증신청 / 인증생략 / 신청서 작성 / 체크리스트 / 수수료)
- 관련 법령 안내 (대기환경보전법 제48조, 시행규칙 제64조 등)

### 2. 인증 안내 탭
- 인증신청 / 인증생략 절차 단계별 안내 (처리기간 포함)
- 인증생략 대상 차량 4종 상세 설명 (특장차, 준이사자, 특수목적차, 개별차)
- 제출처 안내 (한국환경공단, 국립환경과학원)

### 3. 인증신청 서류 탭
- 배출가스 인증신청 필수 첨부서류 9종 상세 안내
- 소음 인증신청 추가 서류 안내
- 필수/조건부 서류 구분 표시
- 온라인/방문/우편 신청 방법 안내

### 4. 인증생략 서류 탭
- 차종별 4개 탭: 개별자동차 / 건설기계 / 특장차 / 준이사자
- 각 차종별 제출 서류 목록 및 상세 설명

### 5. 신청서 작성 도우미
- 4단계 스텝 폼 (신청자 정보 → 차량 정보 → 기술 정보 → 확인)
- 입력 검증 (필수 항목 오류 표시)
- 사업자번호 자동 포맷, VIN 대문자 자동 변환
- 작성 내용 미리보기 및 인쇄 기능

### 6. 서류 체크리스트
- 배출가스 인증 / 인증생략(개별) / 인증생략(특장) 3가지 유형
- 서류별 체크 기능 (진행률 % 표시)
- localStorage 자동 저장 기능
- 메모 기능

### 7. 수수료 안내 및 계산기
- 인증생략 수수료 테이블 (배출가스: 5,500원, 소음: 5,500원)
- 확인 시험 수수료 테이블 (구내/현지조사)
- 자동 계산기 (신청유형 + 차량유형 + 소음포함 + 현지조사 + 차량수)
